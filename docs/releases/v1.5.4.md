# Owlnest v1.5.4

A fix for openings that vanished outside edit mode. These notes cover the changes since **v1.5.3**.

## Fixed

- **An opening added by hand no longer disappears when you leave edit mode.** Since v1.5.3 the card groups the objects that never move, and hides the originals. A door or window created with **+ Opening** hangs under the object it was cut from, so it was hidden along with it: the frame stayed, the leaf was gone. An object that carries an opening is now left out of the grouping. Openings detected by the Sweet Home 3D import were not affected. Thanks to Gogac for the precise report ([#9](https://github.com/MestrieEsteban/ha-owlnest/issues/9)).
- The same applied to a small object attached under a larger one in a Blender model: it could vanish outside edit mode. It stays visible now.

## Updating

Update **Owlnest** in HACS, then force-reload the dashboard browser with **Ctrl+Shift+R** (**Cmd+Shift+R** on macOS). On a wall tablet, reload the dashboard page too.

For a manual installation, replace `config/custom_components/owlnest/` with the folder from this release, including `frontend/` and `brand/`, then restart Home Assistant.
