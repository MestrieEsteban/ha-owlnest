# Owlnest v1.5.3

Smoother camera on wall tablets. These notes cover the changes since **v1.5.2**.

## Improved

- **The camera turns much more smoothly on tablets.** A plan imported from Sweet Home 3D is made of hundreds of separate objects (one per wall, piece of furniture, handle), and each one was drawn on its own, every frame. On a tablet, that is what made the frame rate drop while orbiting. The card now draws the objects that never move together, grouped by look: on a furnished flat, 817 draw calls per frame become 194, with exactly the same picture.
- Doors, windows and shutters are never grouped, since they move. In edit mode, the card goes back to the original objects so you can still click and pick any of them, and groups them again when you leave.

## Updating

Update **Owlnest** in HACS, then force-reload the dashboard browser with **Ctrl+Shift+R** (**Cmd+Shift+R** on macOS). On a wall tablet, reload the dashboard page too.

For a manual installation, replace `config/custom_components/owlnest/` with the folder from this release, including `frontend/` and `brand/`, then restart Home Assistant.
