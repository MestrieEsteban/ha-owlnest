# Owlnest v1.5.2

Several Owlnest cards can now live side by side, each with its own scene. These notes cover the changes since **v1.5.1**.

## Fixed

- **Cards no longer share their scene.** Cards without a `scene_id` all opened the same scene, and choosing a scene in one card changed the others. Choosing or creating a scene from a card's settings now writes it into that card's configuration, as if you had set it in the visual editor: only that card changes, on every device. On a dashboard in YAML mode, the choice is kept in the browser as before.
- **A new card gets its own scene.** A card added from the card picker now starts with a scene of its own and the demo house, instead of sharing `main` with the others.
- **The camera stays close to the model when you switch scenes.** The saved viewpoint was shared between scenes: going from a plan in centimetres to the demo house in metres put the camera hundreds of metres away, out of zoom range. Viewpoints are now kept per scene, and one that no longer fits the model is replaced by the overall view.

## Improved

- **A Scene field in the card's visual editor**, with the list of existing scenes. The model URL is no longer marked as required: you can drop your plan on the card instead.
- The README and the guide describe importing a Sweet Home 3D plan, the doors and windows found for you, and lightening a heavy plan.

## Updating

Update **Owlnest** in HACS, then force-reload the dashboard browser with **Ctrl+Shift+R** (**Cmd+Shift+R** on macOS).

If several of your cards show the same scene, open the settings of each one and pick its scene once, or set `scene_id` in the card editor.

For a manual installation, replace `config/custom_components/owlnest/` with the folder from this release, including `frontend/` and `brand/`, then restart Home Assistant.
