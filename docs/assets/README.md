# Assets

Place your screenshots here for the README.

Suggested files:
- `banner.png` — wide banner image (1280×400 recommended)
- `screenshot-day.png` — daytime view
- `screenshot-sunset.png` — sunset view
- `screenshot-night.png` — night view with lights on
- `screenshot-editor.png` — anchor editor open
- `screenshot-simulation.png` — simulation panel open
- `screenshot-views.png` — camera views bar visible

Use the simulation panel (☀️ button) to capture different times of day.
Use your browser's screenshot tool or `Ctrl+Shift+S` for full-page capture.
