How it works

From dashboard to living floorplan

Three steps to transform Home Assistant into a 3D experience.

01

Load your 3D model

Import any GLB/GLTF — Blender, Sweet Home 3D, Planner 5D. Free camera navigation, shadows, and ambient occlusion out of the box.

02

Place anchors on entities

Press A anywhere to drop an anchor. Link it to any HA entity — lights, switches, sensors, locks, climate. No YAML.

Features

Everything you need

A complete toolkit for building your 3D smart home hub — no coding required.

3D Interactive Scene

Load any GLB/GLTF model — Blender, Sweet Home 3D, Planner 5D. Free camera navigation: zoom, rotate, pan. Shadows and ambient occlusion included.

Synchronized Lights

HA lights drive real Three.js PointLights and SpotLights. Color, temperature, and intensity update live via WebSocket — no refresh needed.

Interactive Anchors

Place HTML overlay markers on any 3D position. Tap to toggle entities, long-press for details. Hover tooltips show entity names in real time.

3D Panels

Float info cards directly inside the scene — room summaries, live sensor values, entity controls. Panels are anchored to 3D space and follow the camera. Three types: Room, Entity, and Info.

Camera Views

Save named viewpoints and fly between them with a smooth animated transition. Trigger from the sidebar or HA automations.

Conditional Rules & Automations

Wire HA entity states to 3D actions. Motion detected? Fly the camera to that room. Door open? Show a warning panel. Build complex IF/THEN/condition chains — no code.

Visual Editor

Blender-style G/R shortcuts, XYZ axis constraints, gizmos, multi-undo/redo, right-click context menu — everything directly in the 3D scene. No YAML editing.

Multilingual

Installation

Up in 4 steps

HACS handles everything. No manual file placement, no config.yaml editing.

Install via HACS

HACS → Frontend → search "Owlnest" → Install → Restart HA

Add the integration

Settings → Devices & Services → Add Integration → "Owlnest"

Add the card

Paste the YAML below into your dashboard, point to your GLB file

Open the editor

Click the pencil icon → press A → place your first anchor → done

YAML 
# Add to your Lovelace dashboard
type: custom:owlnest-card
scene_id: ma_maison
model_url: /local/models/maison.glb

# Restore last camera view
default_view: salon

# Live weather in scene
weather_entity: weather.home
sun_entity: sun.sun
